# 《代数学》写作规范

版本：2.0（2026-09-23）

本规范只规定五卷教材的内容组织与写作质量。凡属 LaTeX、版式、标签和引用命令的细节，见《格式规范.md》；术语、记号、原文与索引，见《术语规范.md》；书目资格、Bib 字段与引文定位，见《书目维护注意事项.md》；编辑、构建、核验和记录步骤，见《工作流程说明.md》。这样分工是为了让每类规则只有一个主管文件，避免多处维护后相互冲突。

## 1. 读者与范围

| 规则 | 设立原因 |
|---|---|
| 本书面向具备本科线性代数、集合、映射和基本证明能力的读者，从高年级本科基础进入研究生共同代数知识及主要分支。 | 明确默认起点，既避免无说明地调用过深知识，也避免反复讲解已经假定的基础。 |
| 五卷围绕运算与结构、生成与关系、局部与整体、正合与导出等相互贯通的主题组织，不写成彼此孤立的专题汇编。 | 读者需要看见概念和方法怎样在不同分支中复用，而不只是得到一组目录。 |
| 各卷是知识组织与出版单元，不是五门固定学期课程，也不要求读者机械地逐卷顺读。阅读次序和证明位置以《工作记录/计划纲要.md》为准。 | 本书允许按基础和目标分流，卷次不能代替真实的知识依赖。 |
| 引入抽象概念时，先说明要解决的问题或已有做法的局限，再给出定义、结果和证明，并配合具体对象。 | 动机和实例能帮助读者理解抽象化的必要性及定义中各条件的作用。 |
| 附录天然属于选读内容，范围限于基本概念、代表性结果、可核验算例和进一步阅读，不以短篇附录替代相关领域的专著。 | 附录应拓宽视野而不虚增主干覆盖范围，也不能让读者误以为已经获得完整理论。 |

## 2. 编、章与节的组织

| 规则 | 设立原因 |
|---|---|
| 新增编级正文单元、重排多章内容、改变主干与选读边界或整体调整解答位置前，先向作者说明方案并取得同意。 | 这类改动会改变全书的教学设计和证明归属，不能由一次局部审稿意见替作者作决定。 |
| 每编设置“本编导读”，说明章节关系、所需基础、阅读次序、学习目标和选读内容；直接依赖图只画证明中实际使用的关系，尚未落实时不预画。 | 导读应帮助读者选择路径，虚构或按章号串联的依赖图反而会误导阅读。 |
| 一章通常依次包含本章摘要、目标与预备知识、正文各节、本章小结和习题；可按内容调整篇幅，但不省略读者真正需要的导航。 | 稳定的阅读入口便于预习和复习，而机械套写相同篇幅只会产生空话。 |
| 本章小结概括本章得到的结果、主要方法及后续用途，放在习题之前，不逐段复述正文。 | 小结应帮助读者形成知识结构，并自然过渡到练习。 |
| 已有实质正文的附录章同样给出与实际内容对应的摘要、目标、预备知识和小结；纯阅读建议不单独占用一个编号节。 | 附录仍须可读，但不应靠形式性栏目或空节制造完成感。 |
| 节首引导只在有实际需要时加入，用于提出问题、说明局部约定、补充眼前必需的概念或提醒易混处，不把小节标题换一种说法再列一遍。 | 引导文字的价值在于建立上下文，重复目录会拖慢进入正文的速度。 |
| 核心定义应能独立查阅：写清对象、运算或映射、量词和新增条件；可以引用已经固定的基础结构，但不能只用几个未展开的术语拼成一句定义。 | 独立完整的定义便于后文准确调用，也减少读者因隐含条件而产生的误解。 |
| 定义采用中文判断顺序：先给定对象及所属环境，再陈述条件，最后命名；不用“称为……如果……”“被称为……如果……”或“一个……是指一个……满足……”的英语式语序。 | 中文教材应让读者先获得判断依据，再看到名称；条件后置会迫使读者回读，并使长定义尤其难以理解。 |
| 定义陈述内须解释本条使用的局部符号，并写明对象所属的环、域、模、空间或范畴；可以依赖前文已经定义的概念，但不能只靠节首散文才能知道符号指什么。 | 读者可能把定义作为资料单独查阅，局部环境缺失会使定义无法独立使用。 |
| 概念按真实依赖顺序引入，基础术语先于使用它的构造；定义后尽量给出可直接核验的例子、条件解释或反例。 | 定理顺序正确并不足够，概念层面的倒置同样会造成循环理解。 |
| 章名和各级标题用自然、具体的中文概括实际对象、结构、方法或问题；“初步”“进阶”“专题”等范围词只在内容确实相符时使用。 | 标题首先承担导航功能，含混或夸大的题名会掩盖章节的真实边界。 |
| “入口”“接口”“贯穿”“闭环”“路线”“定位”等提纲用语不直接充当题名；应改写为具体对象、适用条件、证明方法或相互联系。 | 工作语言不能代替数学内容，读者需要从标题判断自己将学到什么。 |
| 序言说明写作目的、范围、读者、预备知识、篇章安排、使用方法和资料层次；缘起、致谢和成稿信息只写能够如实说明的内容。 | 序言负责建立阅读预期，不应混入无法核实的成书叙事。 |
| 后记回望全书取舍、未展开内容和进一步阅读，不重复序言；引用诗文或其他材料时须与正文有可解释的联系并保留出处。 | 后记的职责是收束和展望，重复书前说明或使用无关引文都会削弱这一作用。 |

## 3. 完成度与内容密度

| 规则 | 设立原因 |
|---|---|
| 本书按可独立阅读的教材写作，不写成定义、定理和结论的摘要汇编。每节应按需要交代背景、定义、主要结果、关键论证和代表性算例。 | 教材的任务是帮助读者重建推理，而不仅是提供结果目录。 |
| 完成度以概念解释、证明链、算例和习题是否覆盖本节任务为准，不设统一页数、字数或段落模板。 | 不同主题所需论证差异很大，机械篇幅指标会拆碎证明或诱发重复。 |
| 标题、提纲和占位文字都不表示内容已经完成。 | 文件结构只说明安排已经建立，不能证明数学和教学任务已经落实。 |
| 概念原则上先定义后使用；前向预告须明确只是预告，不能参与当前证明。 | 这可以防止隐藏的循环依赖和未经说明的知识跳跃。 |
| 中心构造应根据实际需要交代原始数据、良定义、所需公理、映射相容性、泛性质以及唯一性的含义。 | 这些环节决定构造是否真正成立，省略其中任一实质步骤都可能留下数学缺口。 |
| 重要假设须在证明或结论中找到作用位置；有限性、交换性、特征、闭性等条件宜用失败机制、边界情形或反例解释。 | 读者只有知道去掉条件会发生什么，才会理解定理的适用范围。 |
| 每章安排能够实际计算或核验的代表例子，并按主题加入适当的边界情形或反例；反复出现的例子每次应带来新的结构或方法。 | 例子应检验理解并展示理论用途，而不是充当装饰或重复。 |
| 算法性内容必须写明输入、输出、可执行步骤、工作环或基域及有效性条件，并区分存在性证明、有效算法和复杂度结论。 | 理论上存在一个对象并不自动给出可执行算法，混写会夸大结果。 |
| “逐项验证”“同理”“取适当基”“由标准理论可知”等省略语只用于真正机械的整理；若包含良定义、符号、有限性或构造选择等实质环节，必须展开或准确调用已有结果。 | 简略措辞不应掩盖证明最容易出错的部分。 |

## 4. 数学环境的语义

| 环境 | 使用规则 | 设立原因 |
|---|---|---|
| `definition` | 精确引入概念、结构或局部约定。 | 定义确定后文陈述的对象和量词，需要与解释性文字区分。 |
| `proposition` | 陈述普通结论或对象的基本性质。 | 它与核心目标区分后，读者更容易辨认论证层级。 |
| `lemma` | 陈述主要服务于后续证明的工具结论。 | 标明工具角色有助于理解证明结构，但不表示结论本身不重要。 |
| `theorem` | 陈述章节或理论中的核心结果。 | 核心目标应在阅读结构中清楚可见。 |
| `claim` | 用于证明中的局部断言；若断言尚待证明，必须另行明确其状态。 | 环境名称不能把阶段性想法变成已经成立的结论。 |
| `corollary` | 陈述已证结果经过短推导即可得到的直接后果。 | 这能显示结论间的逻辑距离，避免把每个后果都包装成新的主定理。 |
| `remark` | 用于必要的辨析、解释、限制和提醒。 | 注记应补充理解而不打断主证明链。 |
| `example` | 用于需要独立回引的具体构造或算例；短例通常融入正文。 | 只有承担后续作用的例子才需要正式环境，避免环境泛滥。 |
| `conjecture`、`openproblem` | 分别陈述明确未证明的猜想和尚未解决的问题。 | 显式标记未知状态可防止读者把研究问题误认作本书结论。 |
| `exercise`、`optionalexercise` | 分别承载常规练习和确属选做的练习。 | 选做标记应反映知识依赖或难度边界，而不是装饰。 |
| `proof`、`solution` | 分别给出完整证明和完整解答。 | 完整论证应与提示或概要清楚区分。 |
| `proofsketch` | 给出证明概要，并说明省略内容、所用输入和依据。 | 概要只有在读者知道缺少什么以及到哪里补足时才诚实可用。 |

环境类型不能代替证明状态，也不用于包装动机、过渡句或普通后果；具名结果只采用有依据的通行名称，不为无名结论杜撰归属。这样做是为了使环境层级反映数学职责，而不是版面上的强调程度。

## 5. 证明位置与依赖

| 规则 | 设立原因 |
|---|---|
| 每项结果区分“就地证明”“调用已证结果”“前瞻陈述”和“外部引用”，并让状态在邻近文字中可以辨认。 | 读者必须能够判断哪些内容由本书建立，哪些只是预告或借用。 |
| 定理、命题、引理、推论和正式断言在陈述内重复写明影响结论的对象环境与假设，如底环或基域、模的侧别、维数或有限性、交换性、特征及拓扑条件；不得把节首统一约定作为这些条件的唯一出现位置。 | 正式结果常被跳读、检索或单独引用，自足的陈述可防止读者在缺少上下文时误用。 |
| 未标星的主干内容中由本书承诺证明的结果必须给出完整证明，不以名词介绍、证明概要、外部引用或附录中的省略代替。 | 非星主干代表本书的核心教学承诺，证明责任不能悄然降格。 |
| 每个结果原则上只有一个主要证明位置；其他位置可以解释、应用或给出明确标示的第二证明，但不得暗改假设和约定。 | 单一主证明位置可避免重复、版本漂移和循环依赖。 |
| 调用已有结果时，说明所用的具体结论、当前对象、假设为何满足以及由此得到什么；调用同构定理、泛性质、归纳或分类结果时，还须写清相应的核、像、相容条件、参数或穷尽依据。 | 只报定理名称会把关键推理留给读者猜测，也容易掩盖版本不匹配。 |
| 调用已经证明的结果时不重抄整段旧证明；同一证明内紧邻且指代唯一的步骤可以直接承接，基本算术和机械代入不为凑引用添加回链。 | 充分交代依据不等于重复内容；省去真正机械的部分能突出当前证明的新步骤。 |
| 后文反复需要而先前只藏在某段证明中的结论，应提升为边界清楚、可准确定位的正式结果。 | 可复用结论需要稳定的陈述，不能要求读者在旧证明中搜索隐含步骤。 |
| 核对依赖时实际阅读被调用的陈述和证明，确认假设、方向和版本一致，并排除依赖后文、依赖习题或相互循环。 | 引用能够解析或名称相似都不能证明数学调用成立。 |
| 正文及附录的正式证明链不得把章末习题作为唯一前置；若习题中的结论成为必需工具，应将所需陈述和证明提升到正文。 | 习题用于训练，不能承担读者可能跳过的主干证明责任。 |
| 跨卷依赖按纲要规定的阅读分流处理：允许调用后卷中明确承担的基础模块，但须如实写明所需基础和当前证明状态，不假装已在本卷证明。 | 出版次序不总等于学习次序，但跨卷分流也不能成为隐藏前提的借口。 |
| 正文可以把附录用于例子、动机和阅读建议，但不得无说明地依赖附录；选读结果一旦成为主干必需前提，应重新确定其正文位置。 | 选读边界只有在跳过附录后主干仍自足时才有意义。 |
| 延迟证明须明确对应的结果；证明概要须说明省略内容、输入来源和适用假设，且不能替代非星主干已经承诺的完整证明。 | 读者需要准确衔接陈述与论证，并判断概要是否足以支持后续使用。 |
| 一个结果的完整证明尽量放在同一个 `proof` 环境内，不拆成“证明（续）”“证明（完）”；确需分阶段时在同一证明中使用说明性段落。 | 单一环境能保持证明边界、终止符和超链接清楚，也避免跨页或重排后误认中间段已经结束。 |
| 等价条件或长证明包含许多实质步骤时，应分组或分阶段组织。 | 分段能暴露各方向的依赖和关键转折，降低漏证的风险。 |

## 6. 习题

| 规则 | 设立原因 |
|---|---|
| 每章以独立的习题部分覆盖主要概念、构造、结果和方法，题型可包括基础核验、计算、构造、反例、综合证明和选做提高。 | 多种题型分别训练识别、操作和独立证明能力。 |
| 习题数量按本章实际知识点配置，通常每个独立学习任务安排一至两题，不设全书统一的题数上下限。 | 固定配额会造成重复出题，或让知识点因题数已满而没有练习。 |
| 习题不得原样复述正文已证命题；应改变实质条件、要求新的构造或反例、连接不同工具，或补充不影响正文完整性的推导。 | 练习应要求读者作出新的判断，而不是抄写正文。 |
| 每题给出完整解答或明确标示的提示；解答不能只写“同正文”。 | 读者需要可检查的反馈，也需要知道省略的是思路还是完整论证。 |
| 整题依赖选读正文时标为选做；只有个别小问选做时，仅标记相应小问。 | 选做范围应准确，避免读者误判整题的知识要求。 |
| 取材于教材、竞赛题或专业论坛时，保留来源、改编范围和必要的许可信息，并遵守《版权声明.md》。 | 改写不自动消除署名和许可责任。 |

## 7. 教材行文

| 规则 | 设立原因 |
|---|---|
| 使用自然、准确的现代中文；定义先说明对象和条件，再给出名称，避免倒置翻译腔。 | 自然语序能让读者先理解内容，再记忆术语。 |
| 序言、导读、摘要、小结和正文直接说明讨论对象、所需基础、所得结果及用途，避免把“输入”“接口”“闭环”“路线”“定位”等编写或工程用语无解释地带入成文。 | 面向读者的教材语言应描述数学关系，而不是暴露内部工作术语。 |
| 不设机械禁词表；工程词在算法、范畴接口等确有准确含义时可以使用，高频词统计只用于寻找需要人工判断的位置。 | 同一个词在不同语境中的合理性不同，机械替换会损害数学准确性。 |
| 句长和段落长度随数学任务变化，不把所有小节压成等长摘要，也不反复使用空泛连接语。 | 节奏应服从论证层次，而不是服从形式上的整齐。 |
| 正文不写“上述论证完整”“已经验证所有情形”等自我验收语；直接通过条件、分情形和结论展示范围。 | 自我评价不能替代可检查的数学论证。 |
| 抽象结构与具体计算相互解释；同一例子再次出现时，明确当前工作环、基域、特征和作用方向，并增加新的观察。 | 具体语境能防止把只在特殊条件下成立的结论误作一般事实。 |
| 中文句子中的公式要承担清楚的语法成分，不能把公式与英文形容词直接拼成中文谓语。 | 完整语法可以减少歧义，也使数学陈述更自然。 |
| 术语、记号和全书约定遵守《术语规范.md》，本文件不另列主称清单。 | 单一术语来源可避免卷间暗换名称或约定。 |

## 8. 图、表与算法的内容价值

| 规则 | 设立原因 |
|---|---|
| 图只在能够揭示文字不易直接呈现的结构、依赖、作用方向或对应关系时使用，例如子群格、理想包含、交换图、滤过和谱序列。 | 图的价值在于降低理解结构的负担，而不是增加视觉装饰。 |
| 表只在多个对象、条件、结论或边界情形需要横向比较时使用。 | 表格适合比较，不适合把线性叙述切成零散单元。 |
| 不要求每章必须有图表，空章和骨架阶段不预置装饰性对象。 | 图表配额会产生无信息内容，也会制造章节已经完成的错觉。 |
| 图表出现后，正文必须说明读者应从中看到什么，并核对对象、箭头、包含关系、条件和结论的数学正确性。 | 没有解释或关系错误的图表比纯文字更容易造成稳定误解。 |

## 9. 跨卷关系与质量状态

| 规则 | 设立原因 |
|---|---|
| 跨卷调用写明目标卷、章或节、结果名称、所需内容和当前证明状态。 | 五卷独立成书，仅有卷内编号不足以让读者定位，也不足以说明结果是否已经可用；登记步骤由《工作流程说明》主管。 |
| 不为回避跨卷引用而重复完整理论或改变主要证明位置；确需自足时，只补入当前论证所需的最小背景。 | 无控制的重复会导致不同卷版本漂移，过度压缩又会留下隐藏前提。 |
| “骨架已建立”“初稿完成”“编译通过”“正式审核完成”和“定稿”是不同状态，必须按实际达到的层级表述。 | 文件存在、能够排版和数学内容可靠分别回答不同问题。 |
| 进入正式逐章审核前，中心构造、主干证明、术语约定、所需基础、关键例子和习题应达到可检查状态；未解决疑点如实保留。 | 审核需要完整对象，提前宣称完成会掩盖尚未进入检查范围的问题。 |
| 初稿阶段的必要自检不自动算作正式审核，但“尚未审稿”也不能成为省略主干证明或关键条件的理由。 | 写作责任与审稿责任不同，二者都不能替代另一方。 |
