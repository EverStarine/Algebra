# 《代数学》LaTeX 与排版规范

版本：2.0（2026-09-23）

本规范只管理五卷的文件接口、LaTeX 写法、编号、引用和成品版式。数学内容与章节组织见[《写作规范》](写作规范.md)，术语、符号和索引收词见[《术语规范》](术语规范.md)，书目字段见[《书目维护注意事项》](书目维护注意事项.md)，操作步骤与故障处理见[《工作流程说明》](工作流程说明.md)。目录、选读范围与证明归属以[《计划纲要》](../工作记录/计划纲要.md)为准；实际构建命令以[项目 README](../README.md)和脚本为准。

## 1. 文件与共享接口

| 规则 | 原因 |
|---|---|
| 五卷分别以 `Book1/Book1.tex` 至 `Book5/Book5.tex` 为唯一主文件，独立生成 PDF；不另设合订本主文件。 | 独立入口使每卷的编号、书目、索引和构建产物彼此隔离，也允许只构建受影响卷。 |
| 主文件只定义卷元数据并装配书前、正文、附录和书后；正文不直接写在主文件中。 | 主文件保持为清晰的输入链，便于定位缺失文件和调整全卷顺序。 |
| 共用宏、字体、颜色、页面样式放在 `Shared/Preamble.tex`，正文西文字体规则放在 `Shared/TextLetterFont.tex`，索引样式放在 `Shared/algebra.ist`；不得在各卷复制或局部改写同一套定义。 | 单一共享实现可防止五卷版式分叉，并使共享修改能够统一验证。 |
| 五卷共用 `Shared/References.bib`，卷内通过书后入口输出本卷实际引用的文献。 | 共用数据库避免同一文献出现互相冲突的元数据，按卷输出又不会把未引用条目灌入成品。 |
| TeX 源文件使用 UTF-8；各层文件保留指向本卷主文件的 `% !TeX root = ...` 注释。 | 统一编码避免中文和数学字符在不同工具中损坏；根文件注释保证从子文件编辑时仍调用完整文档。 |
| 文件装配层级固定为“主文件 → 编／附录总入口 → 章／附录章入口 → 节文件”；正文最小文件层级为节，小节写在所属节文件内。 | 固定层级使纲要、目录和输入链能够机械核对，避免产生大量只有数行内容的碎片文件。 |
| 图、表的可复用源文件分别放在卷内 `Figures/`、`Tables/`；构建缓存和临时预览放在 `tmp/`。 | 正式输入与可重建产物分离，既便于版本管理，也避免旧辅助文件污染源码目录。 |

## 2. 路径、命名与标签

| 规则 | 原因 |
|---|---|
| 正文路径使用 `BookN/PartNN/PartNN.tex`、`BookN/PartNN/ChapterCC/ChapterCC.tex`、`BookN/PartNN/ChapterCC/SectionCCSS.tex`。`BookN` 不补零，编号和章号各用两位数字，节文件名由两位章号 `CC` 与两位节号 `SS` 组成。 | 固定宽度的名称按目录排序即为阅读顺序，也让目录检查脚本能够无歧义地解析层级。 |
| 附录总入口为 `BookN/Appendices/Appendices.tex`；附录章使用 `AppendixA/AppendixA.tex`，其节文件使用 `SectionA01.tex` 等。 | 附录采用字母编号，单独的命名模式可避免与正文数字章混淆。 |
| 各卷章号跨编连续；每卷附录从 A 重新开始，只显示字母，不带卷号。 | 这与目录和现有引用编号一致，也避免同一卷内出现两套正文章号。 |
| 编、章、节、小节、附录章和可引用对象均设置标签；证明、解和证明概要不设编号标签。 | 标签使重排后的引用仍可解析；无编号证明环境没有可稳定引用的独立序号。 |
| 章标题后的 `\label{...}` 紧接 `\BookChapterNumber{同一标签}`；其他标题和数学环境的标签紧随标题命令或环境开头。 | `\BookChapterNumber` 保存被引章的汉字章号，避免从其他章或无编号单元引用时误取当前计数器；标签靠近对象可减少错绑。 |
| 标签采用稳定、含卷号的语义键，不把可能改动的完整标题写入标签；对象改名或移动但身份未变时保留原标签。 | 稳定标签可避免重命名导致全书引用和外部记录无谓失效。 |
| 推荐前缀为 `bN:part:`、`bN:ch:`、`bN:sec:`、`bN:subsec:`、`bN:app:`、`bN:thm:`、`bN:def:`、`bN:lem:`、`bN:prop:`、`bN:cor:`、`bN:claim:`、`bN:rem:`、`bN:exm:`、`bN:ex:`、`bN:eq:`、`bN:item:`、`bN:fig:`、`bN:tab:`、`bN:alg:`；新增环境按其实际类型选用不冲突的简称。 | 统一前缀可从标签直接识别卷别与对象类型，并降低跨卷重名风险；例与习题分用 `exm`、`ex` 可避免语义混淆。 |

## 3. 页面、页码、页眉与书签

| 规则 | 原因 |
|---|---|
| 书名页用 `\MakeBookTitle`，目录用 `\MakeBookContents`；书名、卷次、副标题、作者和日期只通过卷元数据传入，不在单卷重做字号或间距。 | 共享入口保证五卷封面和顶级 PDF 书签一致。 |
| 书名页后保留一张计入页序但不显示页码的空白页。 | 双面成书时使序言从奇数页开始，并保持现有物理页序约定。 |
| 书前使用小写罗马页码，正文与附录使用阿拉伯页码，书后重新使用小写罗马页码。 | 不同区域的页码体系清楚区分正文和辅助材料，也与五卷现有入口一致。 |
| 每编用 `\BookPart{编名}{标签}`，编导读用 `\BookPartGuide`；每编从奇数页开始，编题页后留一张真正的空白页。 | 共享命令同时处理分页、页样式、标签和书签，避免各编手工实现后出现差异。 |
| 普通正文页偶数页眉显示页码与章标题，奇数页眉显示进入本页前最后有效的节标题与页码；新节和章末习题的标记从后续页生效。 | 页眉应帮助读者定位跨页内容，而不应因本页末尾刚出现新标题就提前改变。 |
| 编题页和章首页不显示页眉横线，页码置于页脚中央；真正的空白页不显示页眉、页脚和可见页码。 | 特殊页面需要与连续正文区分，空白页也不应残留上一单元的标记。 |
| 序言、编导读、后记、参考文献、索引等无编号章级单元的后续页显示该单元自己的页眉标题。 | 无编号单元若沿用上一正文节页眉，会给出错误的阅读位置。 |
| 书名页、目录、附录总入口和书后各单元保持顶级 PDF 书签；不得为共享命令已生成的入口再手写同名书签。 | 唯一的书签树便于导航，重复书签会制造同名节点或错误层级。 |
| 有编号的书签包含编号：编为“第几编”，正文章为“第几章”，附录章为“附录 A”等；节、小节分别加 `x.x`、`x.x.x`。无编号单元不补虚构编号。 | 书签与目录及正文位置对应，读者可以直接按编号查找。 |
| 编章页面样式、字体、颜色和间距只在共享样式中调整，不在单章用 `\ctexset`、页眉命令或固定空白临时覆盖。 | 局部覆盖难以追踪，并会使同级页面在五卷中逐渐失去一致性。 |

## 4. 标题、选读与附录

| 规则 | 原因 |
|---|---|
| 选读章、节、小节分别用 `\OptionalChapter`、`\OptionalSection`、`\OptionalSubsection`；标题参数中不手写星号。 | 星号属于编号而非标题，共享宏可同时保证正文、目录、页眉和书签中的显示一致。 |
| 选做习题用 `optionalexercise`，不在题名中再写“选做”或星号。 | 环境已让星号随习题号显示，手写会造成重复或目录文字不一致。 |
| 数学记号自身的 `*` 不按选读标记处理。 | 数学星号表达对偶、伴随等含义，误套选读宏会改变数学内容。 |
| 附录天然作为补充阅读，不加选读星号；每卷只设一个由 `\BookAppendixPart` 建立的无编号“附录”编，各附录章挂在其下。 | 单一附录入口保持目录和书签层级清楚，额外星号不提供新信息。 |
| 附录节确有实质小节时，在纲要用四级标题 `#### A.n.n` 列出并与源码同步；有意不设小节的短节在纲要标记 `<!-- 短节：不设小节 -->`。 | 目录检查脚本需要区分“计划中的短节”和“遗漏了小节正文”，显式标记可避免机械补层级。 |
| 章末习题入口统一用 `\BookExercises`，每章只生成一个“习题”目录项和书签。 | 共享入口会同时更新页眉和目录；另加 `\section*` 或手写书签容易遗漏页眉或产生重复节点。 |
| 题名是否选读、层级如何划分由《计划纲要》和《写作规范》决定；本文件只规定相应 LaTeX 入口。 | 内容决策与排版实现分离，避免格式文件维护第二份易漂移的目录规则。 |

## 5. 环境、编号与列表

| 规则 | 原因 |
|---|---|
| 定义、例、命题、引理、定理、推论、断言、猜想、开放问题和注记共用“章.节.本节流水号”，但保留各自的引用类型；无分节附录显示 `A.1`，有分节附录显示 `A.2.1`。 | 共享流水号反映正文顺序，独立类型又能让 `\cref` 输出正确名称；附录省略无意义的零级编号。 |
| 习题使用独立计数器，每章从 1 开始，显示“章号.章内序号”；附录习题显示 `A.1` 等，选做题与普通题共用此序列。 | 习题数量与定理环境无关，独立编号便于章末练习增删且不扰动正文结果编号。 |
| 具名结果把短题名写在环境可选参数中，编号由环境生成；不得在题名中手写编号。 | 自动编号能随结构调整更新，并同步服务于目录、引用和超链接。 |
| `proof`、`solution`、`proofsketch` 不编号，终止符由环境产生，不手写“证毕”或额外方块。 | 证明与所证结果保持从属关系，自动终止符可避免重复和位置错误。 |
| 定理类中文正文采用共享楷体，非数学西文保持正体；证明、解和证明概要只有标题用楷体，正文用普通正体；数学字体不随文字环境改变。 | 这种字形分工已作为全书的层级提示，同时避免西文或公式被意外倾斜。 |
| 普通有序列表三层依次为 `1.`、`1)`、`a)`；等价命题使用 `equivalences`，两层依次为 `I.`、`i)`；不使用四层以上嵌套。 | 不同列表语义拥有稳定编号，限制深度可保持版心清楚并减轻交叉引用歧义。 |
| 需要引用的列表项在 `\item` 后立即设置 `\label`，并用 `\itemref{...}` 引用。 | `\itemref` 让括号和序号整体成为链接，且列表增删后无需手改编号。 |

## 6. 交叉引用与链接

| 规则 | 原因 |
|---|---|
| 定理类、图、表和算法优先用 `\cref`，公式用 `\eqref`；不在类别名后拼接裸 `\ref`。 | 类型和编号由同一个链接生成，可避免类别文字与目标不一致，也扩大可点击区域。 |
| 章、节、小节和附录分别用 `\chapref`、`\secref`、`\subsecref`、`\appref`；宏外不再重复“第”“章”“节”等字样。 | 这些宏已包含中文类别和间距，重复书写会产生冗词或不完整链接。 |
| 同类对象并列引用时，每一项都使用完整引用宏；不得让后续项退回手写编号。 | 每个目标都应可点击，增删对象后也应各自自动更新。 |
| 不手写会随增删变化的章、节、公式、环境或列表编号。 | 自动引用是结构调整后保持正确性的唯一稳定来源。 |
| 章、节标签只用于阅读导航；证明中的关键调用应指向具体定理、命题、引理、推论或公式标签。 | 章节范围不能说明实际使用了哪条结论，也不能替代假设核对。 |
| 引用宏与相邻中文或全角标点之间不加源码空格或 `~`；因换行产生不需要的空格时用行末 `%` 抑制。 | 共享宏已经处理中文间距，人工空格会在成品中形成不一致的空白。 |
| 五卷独立 PDF 之间使用明确的卷名、位置和结果名称作文本引用，不用卷内引用宏伪造跨卷链接；证明状态与登记步骤遵守《写作规范》和《工作流程说明》。 | 五卷分别生成，卷内引用目标不能跨 PDF 解析；本文件只主管引用的排版形式。 |
| DOI 和网页使用标准 URI 链接，不加入强制新窗口的 PDF JavaScript。 | 标准链接在不同 PDF 阅读器中兼容性更好，也不替读者决定打开方式。 |

## 7. 段落、字体与公式

| 规则 | 原因 |
|---|---|
| 两个连续的普通叙述段落先用空行分段，再在两段之间独立写 `\ProseParagraphBreak`；标题、列表、公式、定理、图表、引文等结构边界，以及 `proof`、`solution`、`proofsketch` 内不使用该命令。 | 该命令只补充普通散文段距；在环境边界重复加入会叠加垂直空白。 |
| `chaptersummary` 中的连续普通段落沿用 `\ProseParagraphBreak`；单段小结不为形式统一而拆段。 | 小结与正文采用同一散文节奏，同时避免制造没有内容依据的分段。 |
| `chapterabstract`、`learninggoals` 及其后的正文使用真实空行结束段落；不以手工空格或固定 `\hspace` 模拟首行缩进。 | TeX 只有在真正结束段落后才能正确恢复缩进，手工位移会随字体和版心变化而失准。 |
| 诗歌和短引文使用 `quote` 或语义等价的 `poemquote`，出处使用 `\quoteattribution{...}`；不以手工空格模拟居中或右对齐。 | 共享环境统一处理楷体、对齐和边距，手工空格在换行或版心变化后会错位。 |
| 行内公式写作 `\(...\)`，行间公式使用 `\[...\]` 或标准公式环境；TeX 源码不使用 `$...$` 或 `$$...$$`。 | 统一的 LaTeX 语法更容易检查定界是否成对，也避免 `$$` 绕过文档类的行间公式设置。 |
| 行间公式仅在需要引用时编号并设置标签。 | 只给会被调用的公式编号，可减少无意义序号并保持阅读连续。 |
| 首次绑定后文复用的记号可用 `\coloneqq`；既有等式、局部假设和临时命名仍用 `=`，源码不写 ASCII `:=`。 | 区分定义与等式有助于阅读，但把所有“定义”句机械改成定义号会增加符号噪声；ASCII 写法又不符合成品排版。 |
| 行内公式与相邻正文文字之间保留正常源码空格，标点前不强行加空格；引用宏的间距按上一节的专门规则处理。 | 这让中西文和数学间距由 XeCJK 与数学排版统一计算，避免人工空白忽大忽小。 |
| 字体、字号、颜色、行距、段距和数学字形只改共享设置；正文不得局部另选一套全书字形。 | 集中设置可保证五卷一致，并使字体缺失或字形异常能够在一处修复。 |
| 粗正体字母或数字使用 `\mathbf` 或 `\symbfup`，粗斜体使用 `\symbfit`；不得仅凭 `\boldsymbol` 的命令名认定当前字体已有粗字形。 | 这些命令与共享的 Unicode 数学字体及 AMS 覆盖相匹配，可避免源码意图与实际字形不一致；空集等符号选择由《术语规范》主管。 |
| 定理环境中的术语强调、固定运算符和全书复用的复合符号使用共享宏或标准数学命令（例如正规闭包用 `\NormalClosure`）；具体主称和符号选择遵守《术语规范》。 | 共享宏可使同一符号在正文和索引中保持相同字形与间距，而术语和数学语义不应在格式规范中另立一套规则。 |
| 真实嵌套的数学定界符须逐层清楚区分大小，可按内层普通、中层 `\bigl...\bigr`、外层 `\Bigl...\Bigr` 等递增；复合符号（如范数双竖线、正规闭包双尖括号）不拆成两层。 | 若相邻两层括号等高，读者难以辨认表达式的结合范围；复合符号本身则只承担一层定界意义。 |
| 括号大小以成品中能够辨认为准；源码已有大小命令但仍有具体显示疑点时才定向检查相关公式，并提高相邻层级，不例行渲染全书公式。 | 字体会影响不同尺寸命令的实际差异；有疑点时看目标页面足够，批量图片检查成本高且不能替代源码核对。 |
| 过高的行内分式改为行间公式；容易连读为单一记号的绝对值、范数或其他因子之间用 `\cdot`，普通无歧义单项式不机械加点。 | 控制行内高度可保持稳定行距，乘号只在确有歧义时出现可减少视觉噪声。 |
| 行内映射使用 `\rightarrow`、`\mapsto`，行间映射使用 `\longrightarrow`、`\longmapsto`；集合构造式保留适当数学间距，如 `\{\,x\in X\mid P(x)\,\}`。 | 长箭头在独立公式中更易读，集合构造式的细间距能分清定界符、元素和条件。 |
| 交换图使用 `tikzcd`，并核对箭头方向、复合次序及交换或反交换条件。 | 语义化图形源码便于维护，但方向或路径错误通常不会触发 TeX 报错，必须按数学关系核对。 |

## 8. 图、表与算法

| 规则 | 原因 |
|---|---|
| 需要在正文中引用的图、表和算法均设置编号、标题和标签；证明内部的小型交换图可保持非浮动。 | 正式对象需要稳定引用，局部推导图若浮动反而会远离其解释。 |
| 目录只收短题名，长说明写在正文标题中，例如 `\caption[短题名]{短题名。补充说明}`。 | 简短目录项便于扫描，也避免长说明破坏图表目录版面。 |
| 图目录、表目录或算法目录只在该卷已有相应正式对象后接入，并在书前建立顶级书签；已有共享入口时必须复用。 | 空目录没有导航价值，也会让骨架看起来像已经具有成品内容；复用现有入口可避免重复书签。 |
| 表格按内容分配列宽，优先使用项目已加载的 `booktabs`、`longtable`、`tabularx` 等接口；不得仅凭“无 Overfull”认定表格可读。 | 表格即使未溢出，也可能存在列宽失衡、文字拥挤或阅读顺序不清。 |
| 已按《写作规范》满足内容要求的算法，使用共享的 `algorithmsteps` 接口排印输入、输出和编号步骤。 | 内容是否构成算法由写作规范判断，本文件只统一其 LaTeX 实现和步骤定位。 |
| 新增或大改图、交换图、大型表格后，除检查 TeX 日志外，只定向查看相关页面的缩放、跨页、文字辨识和阅读顺序。 | 这些空间关系仅靠日志不能完全判断，但无需因此批量渲染无关页面。 |

## 9. 书目、索引与书后输出

| 规则 | 原因 |
|---|---|
| 书目使用 `biblatex + biber`；正文用 `\cite`，书后用 `\PrintBookBibliography`，不得以 `\nocite{*}` 把全库写入某卷。 | 每卷只应列出实际引用的资料，共享入口也能正确处理暂无引文的骨架。 |
| 书目数据库的字段、版本和来源按《书目维护注意事项》维护，不在本规范重复规定。 | 书目真实性与数据模型由专门文件统一管理，避免两份准则发生漂移。 |
| 参考文献中的非数学西文字母使用共享的 Pagella 正体并保留必要粗细，书名、中文和标点不由书目样式自动改为斜体；数学内容仍使用全书数学字体。 | 字体属于输出样式，应在共享层统一实现，不能靠改写书名、作者或其他数据库字段达到视觉效果。 |
| 中文、外文、符号分别写入 `chinese`、`foreign`、`symbols` 三类索引，并分别运行处理器；输出统一使用 `Shared/algebra.ist`。 | 三类条目的排序逻辑不同，合并处理会破坏中文、外文和符号各自的次序。 |
| 索引收词、主称和别称规则遵守《术语规范》；排版时使用共享索引宏，不在卷内手写索引输出。 | 术语文件决定“收什么”，共享宏决定“怎样排”，分开职责可避免内容规则与样式实现重复。 |
| 索引采用共享的小号双栏样式；页码和多页码分隔格式不在卷内局部重设。 | 五卷索引应具有一致的扫描节奏和页码对齐方式。 |
| 书后通过 `\PrintBookIndex` 读入真实索引；空索引只保留结构入口，构建时不得复用旧 `.ind`。 | 旧索引可能包含已删除词条或错误页码，空入口也不应被误认为已有完整索引。 |
| 后记、参考文献和三类索引保持书后顶级书签，不挂在最后一个附录节点下。 | 这些单元属于全卷辅助材料，而不是某个附录的子内容。 |

## 10. 构建与验收接口

| 规则 | 原因 |
|---|---|
| 构建命令、影响范围、日志检查、临时产物和视觉核验步骤统一遵守《工作流程说明》；本规范不复制操作流程。 | 操作步骤只有一个主管文件，才能避免脚本更新后出现两套不同说明。 |
| 格式验收至少覆盖输入链、编号与标签、引用与书签、书目和非空索引的实际读入、缺字、Overfull 及明确版面疑点。 | 这些项目直接决定成品的导航、可见性和版心可用性，是排版规范需要明确的验收目标。 |
