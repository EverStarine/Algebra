# 《代数学》术语、数学约定与索引规范

版本：2.0（2026-09-23）

本文件主管中文主称、原文、数学约定、稳定记号以及索引收词。排版实现见《格式规范》，术语采集与核验步骤见《工作流程说明》。本规范只保留当前采用的规则；历次替换数量、旧版取舍和单次核验过程不作为长期规范。

## 1. 术语选择原则

| 规则 | 设立原因 |
|---|---|
| 正文和标题优先使用中文主称；人名、专名、标准缩写和数学记号保留通行原文，类别词用中文，如“Galois 理论”“Noether 环”。 | 中文主称便于连续阅读，保留专名原文则避免生造译名或丢失可检索性。 |
| `abelian` 用来表示交换性质时，本书主称统一译作“交换”，如交换群、交换范畴、交换 Lie 代数和交换化；首次定义可保留拉丁拼写的 Abel 异名，真正的人名或专名也保留 Abel，如 Abel–Ruffini 定理。不使用“阿贝尔”音译。该规则只约束本书主称，不要求删除拉丁异名。 | 统一中文命名可避免同一词根在不同分支中一处意译、一处音译；拉丁异名和人名仍保留检索与文献对照价值。 |
| 同一概念全书只设一个主称；有依据的异名在首次定义或必要辨析处说明并登记索引，后文仍使用主称。 | 主称统一可防止标题和跨卷引用漂移；保留异名则帮助读者识别其他教材和论文中的不同称呼。 |
| 作者已经明确指定的主称优先；新增主称须核对实际定义、中文专业用法和可靠来源。 | 术语首先要保持全书一致，同时避免仅凭英文词形或搜索摘要推断中文名称。 |
| 只有目录、简介或摘要可见时，只据此确认名称和主题，不声称已经核对定义或证明。 | 证据范围必须与结论相称，否则会把文献线索误写成实读结论。 |
| 尚无稳定中文译名时保留原文并登记待核，不临时制造貌似权威的译名。 | 暂留原文比错误译名更容易复核和更正。 |
| 引用他人作品或原话时保留该来源的实际用语，必要时注明本书主称。 | 引文应忠于来源，同时不能因此改变本书统一术语。 |

## 2. 本书主称

下表给出当前必须保持的主称。每条的“使用边界与原因”既说明为何采用，也限制其机械扩张。

| 中文主称 | 原文 | 使用边界与设立原因 |
|---|---|---|
| 本原单位根 | primitive root of unity | 指乘法阶恰为 $n$ 的 $n$ 次单位根；采用“本原”是为与本原元、本原元素保持通行用法，并避免旧称“原始单位根”。 |
| 交换群 | abelian group | 群运算满足交换律；正文统一采用该主称，首次定义注明拉丁异名“Abel 群”，帮助读者对照其他资料，后文不以异名替代主称。 |
| 交换范畴 | abelian category | 指满足相应核、余核和正合性公理的加性范畴；正文和标题采用该主称，首次定义保留拉丁异名“Abel 范畴”，并与“加性范畴”保持概念区分。 |
| 泛性质 | universal property | 用于以映射存在唯一性刻画对象；作者指定该主称，“普遍性质”“万有性质”只作有依据的异名。 |
| 容度 | content | 在唯一分解整环或 GCD 整环语境中指系数的最大公因子，通常只确定到相伴；一般环上若使用内容理想须另行定义。使用专名可避免与普通叙述中的“内容”混淆。 |
| 全次数 | total degree | 指非零单项式指数和的最大值；加“全”是为区别关于单个变量的次数。 |
| 群展示 | group presentation | 用于群的生成元与关系；作者指定“展示”，定义处可注明“群呈示”，但不把这一选择机械套到所有对象。 |
| 模展示；有限展示模 | presentation of a module; finitely presented module | 用于模的生成元与关系；与群展示保持同一主称，也便于统一“展示矩阵”“分次展示”。 |
| 线性生成空间 | linear span | 指给定向量的有限线性组合；不用“线性闭包”作主称，以免被误解为拓扑闭包。主记号为 $\operatorname{span}_k S$。 |
| 友矩阵 | companion matrix | 专指由首一多项式系数构成的矩阵；“伴随矩阵”保留给 adjugate matrix，防止两个常见矩阵同名。 |
| 规矩数 | constructible number | 作者指定为主称；“可构造数”“可作图数”在首次定义处作别称。几何动作仍可说“可作图”。 |
| 稳定子群；稳定化子 | stabilizer | 两者都指固定指定点的全部群元素组成的子群；单个群元素只说“固定该点的元素”，不另称“稳定子”，以免把元素与标准术语所指的子群混淆。正文以“稳定子群”为主称，“稳定化子”只在首次定义时作为别称。 |
| Lindemann–Weierstrass 定理 | Lindemann–Weierstrass theorem | 使用一般定理的单变量超越性推论时明确说明推导，不把圆周率超越性与一般定理写成同一陈述。 |
| 零化；零化子 | annihilation; annihilator | 用于乘法或作用把对象送到零的语境；正文动词用“零化”，“湮灭子”只作别称，便于与中文文献对照。 |
| 归一化 $2$-余圈；$2$-余边 | normalized 2-cocycle; 2-coboundary | 用于群扩张与群上同调；“归一化”明确单位元处取零的附加条件，“余圈”“余边”与后续各阶上同调术语保持同一构词，不使用“二余循环”“二余边界”另立一套名称。 |
| 消解 | resolution | 用于同调代数中的自由、投射、内射等消解；作者指定该主称。“预解”“解消”“分解”只在相应同调语境中作异名。 |
| 合冲模；Hilbert 合冲定理 | syzygy module; Hilbert's syzygy theorem | 用于模的生成关系；固定这一译名可避免与“协同”或内射方向概念混淆。 |
| 全函子；忠实函子；全忠实函子 | full functor; faithful functor; fully faithful functor | full 译作“全”以区别普通“充分条件”；本质满函子另行定义。 |
| 正合偶 | exact couple | 用于谱序列构造中的特定结构；专名固定后可避免与普通“精确”措辞混杂。 |
| 好三角 | distinguished triangle | 用于三角范畴的指定三角；作者选择该主称，其他译名只按实际文献对照。 |
| 平展 | étale | 用于相应环同态、代数和几何对象，并沿用“形式平展”“平展上同调”；固定主称便于跨卷一致。 |
| 投射 | projective | 用于模、对象和维数；“射影空间”“射影表示”按既有专名保留，避免按英文词形全局替换。 |
| 内射 | injective | 用于模、对象和维数；与映射的“单射”分开，避免对象性质与映射性质混称。 |
| 正合 | exact | 用于序列、函子和范畴结构；保持同调代数中的通行主称。 |
| 关联素理想 | associated prime | 作者指定为主称；“相关”“相伴”“伴随”仅作来源中的异名，防止同一对象跨卷多名。 |
| 基座 | socle | 指模的全部简单子模之和；保留原文 socle 便于检索，并与模的根区分。 |
| 初等、完全、幂和对称函数 | elementary, complete, power-sum symmetric function | 三类对象分别命名；elementary 固定为“初等”，避免与一般“基本”混用。 |
| 支集挠子函子（$I$-挠子函子 $\Gamma_I$） | torsion functor | 指被 $I$ 的某个幂零化的元素所成子模；用“挠子”以区别 torsor。 |
| 联络；连接同态 | connection; connecting homomorphism | 两者是不同对象；分别命名可防止把联络算子误当作复形中的连接映射。 |
| 圈；边界 | cycle; boundary | 用于链复形与同调；固定后可与循环群、循环模和置换轮换区分。 |
| 态 | state | 用于算子代数中满足正性和归一化的泛函；不用普通“状态”，以突出其数学条件。 |
| 固有；固有性 | proper; properness | 用于概形态射；须随定义说明分离、有限型和普遍闭，避免仅凭汉语字面使用。 |
| 拟紧；拟紧性 | quasi-compact; quasi-compactness | 只要求每个开覆盖有有限子覆盖，不附加 Hausdorff 条件；固定译名可防止误加紧致性的分离条件。 |
| 投射有限 | profinite | 用于相应群和空间的逆极限拓扑结构；不把“有限”误解为底集合有限，别称“pro-有限”只作对照。 |

## 3. 易混概念

### 不变量与对合补充中的用语

| 主称与原文 | 使用约定 |
|---|---|
| 不变多项式（invariant polynomial）；不变环（invariant ring） | 指给定群作用下固定的形式多项式及其子环；有限域上不以点集函数相等替代多项式相等。不变环索引排序键统一为 bubian-huan。 |
| Reynolds 算子（Reynolds operator） | 保留人名，采用“算子”；有限群平均版本必须注明群阶可逆。它是不变子环的模投影，一般不是环同态。 |
| 型的相似变换（similitude）；乘子（multiplier） | 前者允许型的取值统一乘以非零标量，后者指这个标量；与线性算子矩阵的相似、共轭问题分别表述。 |
| 迹型（trace form） | 注明来自域扩张、代数或所选对合；对合迹型的记号与定义写出所用约化迹，不将不同来源的型混同。 |

这些约定对应各卷本轮已写定义；第五卷待写目录中的“协变式（covariant）”在正式写作时还须明确其等变映射定义及采用的群作用。

| 概念组 | 规则 | 设立原因 |
|---|---|---|
| 交换群 / 交换范畴 | 两者都按 `abelian → 交换` 的原则命名，但分别按群公理和范畴公理定义；不能仅凭中文“交换”互相推出。 | 统一意译不表示两个概念具有相同定义。 |
| Jacobian / Jacobi | 偏导数矩阵写 Jacobian 矩阵；Jacobi 恒等式及相应专名保留 Jacobi。 | 同一人名的不同派生形式已经固定用于不同数学对象，应按对象采用通行专名，不能按词形互换。 |
| Hermitian / Hermite | 复半双线性型用 Hermitian 型；Hermite 只用于相应人名和专名。 | 同一人名的不同派生形式已经固定用于不同数学对象，应按对象采用通行专名，不能按词形互换。 |
| bar 构造 | bar 小写，除非位于句首；译名按实际来源说明。 | bar 不是人名，不应错误大写。 |
| torsion / torsor | 模的挠元、挠子模及 $\Gamma_I$ 属于 torsion；torsor 另行定义。 | 两词形近但概念无直接等同关系。 |
| 切复形 / 余切复形 | 余切复形记为 $L_{B/A}$；讨论切复形或导出对偶时说明底对象、系数和假设。 | 二者通常通过对偶联系，并非同一个复形。 |
| derived / derivation | 分别按“导出”和“导子”所属概念命名。 | 共同词根不能代替数学定义。 |
| 基座 / 模的根 | 分别定义，不以“简单子模”或“极大子模”的字面关系相互代替。 | 两个结构位于模的不同层面。 |
| Young 表相关对象 | Young 表（tableau）、行表类（tabloid）、行表类的列交错元（polytabloid）分别定义与登记；后者可在对象明确时简称列交错元。 | 作者指定两项主称；行表类是等价类，列交错元是由它构造的线性组合，不译作“多重表”。 |
| holonomic / holomorphic | holonomic D-模暂保留原文；不译作“全纯”。 | 两词含义不同，误译会改变对象类别。 |
| Positivstellensatz | 保留德文专名，并在首次使用时写明所用版本。 | 该名称涵盖多个版本，强行指定唯一中译容易掩盖假设差异。 |
| 矩阵迹 / 迹态 | 只有归一化迹 $a\mapsto\operatorname{Tr}(a)/n$ 才称矩阵迹态。 | 普通迹在单位元上的值为 $n$，不满足态的归一化。 |
| 有限模 / 有限长度模 / 有限集合 | “有限模”只指有限生成模，其他含义完整写出。 | “有限”在三种语境中的条件不同。 |
| 单、简单、不可约、不可分解 | 按群、模、表示和分解对象分别定义，不全局互换。 | 这些词在不同对象上对应不同子对象条件。 |
| 正规、正则、Cohen–Macaulay、光滑等 | 每次说明适用对象和必要假设。 | 相似汉语不能替代环、局部环、态射或几何对象上的定义。 |
| 理想商 / 商环 / 商代数 | `ideal quotient` 主称“理想商”，记 $(I:J)$；$R/I$ 称商环，代数模双边理想称商代数。 | 三者的对象类型和所在位置不同。 |
| 乘法集饱和 / $I:J^\infty$ | 前者要求某个分母，后者要求某个幂理想的全部元素；仅在单元素情形直接相合。 | 多生成元时两种量词不同。 |

## 4. 数学约定与稳定记号

### 4.1 全书默认约定

| 规则 | 设立原因 |
|---|---|
| 环默认含幺，环同态默认保持单位；交换性、Noether 性、有限生成性和特征按具体结果明示。 | 固定默认值可减少重复，但决定定理真假的附加假设不能隐藏。 |
| 非交换模论默认左模；张量积、诱导和限制逐项写明右模、左模和双模作用。 | 非交换情形中标量次序影响公式和函子方向。 |
| 上链复形微分升次，移位满足 $C[1]^n=C^{n+1}$、$\mathrm{d}_{C[1]}=-\mathrm{d}_C$。 | 复形、映射锥、谱序列和截断的符号必须全书一致，才能可靠调用公式。 |
| 微分、导子、上同调微分及边界算子的拉丁 $d$ 用直立体 `\mathrm{d}`；表示维数、次数或一般参数的 $d$ 保留斜体。偏导符号和希腊字母不因此改写。 | 字形区分固定算子与参数，避免把所有同名字母机械替换。 |
| 反复使用的算例每次说明工作环、基域和特征。 | 同一公式在不同底对象或特征下可能改变含义或失效。 |
| 固定运算符使用既有命令或 `\operatorname`，如 $\operatorname{Hom}$、$\operatorname{Ext}$、$\operatorname{Spec}$。 | 统一字形并防止运算符被误排为变量乘积。 |

### 4.2 稳定记号

| 对象 | 本书记号 | 设立原因或边界 |
|---|---|---|
| 集合 $X$ 上的对称群 | $S_X$；$X=\{1,\ldots,n\}$ 时写 $S_n$ | 与一般置换群区分；$\operatorname{Sym}(X)$ 只在首次定义处作通行异写。 |
| 对称代数与对称幂 | $\operatorname{Sym}(V)$、$\operatorname{Sym}^m(V)$ | 对象类型已由参数 $V$ 表明；涉及不变张量时仍须核对特征。 |
| 映射与同态集合 | $Y^X$、$\operatorname{Hom}(G,K)$ | 前者不要求保持结构，后者要求群同态，记号应显示区别。 |
| 空集 | $\varnothing$ | 全书使用同一标准符号，避免 `\emptyset` 与 `\varnothing` 混排造成无意义的字形差异。 |
| 二面体群 | $D_{2n}$ | 下标表示群阶；首次出现时提醒其他文献可能以下标表示边数。 |
| 交换子 | $[x,y]=xyx^{-1}y^{-1}$ | 文献常有相反约定，固定方向才能正确移用恒等式。 |
| 半直积 | $N\rtimes_\alpha H$ | 记号显示 $H$ 对 $N$ 的作用；作用明确后才可省略 $\alpha$。 |
| 图的基本群 | $\pi_1(\Gamma,o)$ | 采用通行记号，避免为一次构造另造主记号。 |
| 有限支集直积 | 直接描述为直积中的有限支集子群 | 不引入非标准 `fin` 上标，也不把非交换群的该构造误当作余积。 |

新增稳定记号须先检查五卷已有用法；必要的局部变量只需就地说明。这样既避免符号冲突，也不为只出现一次的对象增加全书负担。

记号首次出现时还须说明对象类型，尤其区分集合与群、元素与映射、商集与商群。原因是相同字形可以承载不同结构，只让读者从记号猜测会掩盖后续运算所需的条件。

遇到多种通行记号或方向约定时，本书选定一种并说明适用范围；审稿时不把其他通行约定本身判作数学错误，而是先转换后核对。原因是约定可以不同，真正需要一致的是同一论证内部的定义和推导。

## 5. 首次出现、强调与索引

| 规则 | 设立原因 |
|---|---|
| 专门术语在每卷首次正式定义或明确回顾处使用 `\term[排序键]{中文主称}[原文]`。 | 五卷可独立阅读；首次同时登记中文和原文，便于索引与文献检索。 |
| 具名定理、公式和准则首次正式引入时也给完整原文，但定理环境标题只放简明名称。 | 保留原文可检索性，同时避免标题宏嵌套破坏编号和书签。 |
| 同卷后文只用主称，不反复附原文。 | 避免正文臃肿。 |
| 主称首次引入可按共享样式加粗；普通修辞强调不用术语格式。 | 术语标记承担索引职责，不应变成泛用强调手段。 |
| 已有明确中文本名的人物优先用中文本名；否则保持统一拉丁拼写，不自行推测中文名。 | 人名必须可核验，书目署名也不应为配合正文而改写。 |
| 中文索引按主称排序，同一主称共用一个排序键。 | 避免同一概念因拼音或别称不同产生多个分散条目。 |
| 异名只在实际说明处用 `\termidx` 登记真实页码，不生成“见某某”转引，也不复制主称全部页码。 | 索引应把读者带到真正解释异名的位置。 |
| 外文异名在实际说明处用 `\foreignidx`；不以临时英译填充。 | 外文索引同样需要真实来源和稳定拼写。 |
| 稳定符号在定义处用 `\symidx` 登记一次；局部证明变量通常不收录。 | 符号索引用于查找全书约定，不应被临时记号淹没。 |
| 索引参数中的 `!`、`@` 和竖线字符按索引语法处理；范数使用 `\lVert`、`\rVert`。 | 这些字符具有处理器语义，未经保护会破坏条目或页码。 |

## 6. 维护规则

### 第五卷第二编的具体约定

- tabloid 采用作者指定的“行表类”；polytabloid 采用“行表类的列交错元”，对象明确时简称“列交错元”。首次定义保留英文与构造，主称、简称索引登记实际解释页码，不生成转引条目。这里记录作者的用词选择，不宣称两项已经获得统一官方审定。
- 对称函数的 Hall 配对采用有理数上的双线性形式；复化后若与特征标内积比较，明确改用第一变量共轭线性的 Hermitian 配对。
- 使用“投射覆盖”“基座”“顶”“块”“分解数”“缺陷群”；底层代数的 Cartan 矩阵与后续根系的 Cartan 矩阵分开说明。前者行对应简单模、列对应不可分解投射覆盖。
- 统一采用“\(p\)-模系统”（\(p\)-modular system），分别写出特征零域、离散赋值环及剩余域；分裂与所需单位根条件另行明示。
- 箭图路径乘法 \(qp\) 表示先走 \(p\) 再走 \(q\)。采用左模，箭 \(a:i\to j\) 满足 \(a=e_jae_i\)，投射表示为 \(P_i=kQe_i\)，对应的 Ext 箭向为 \(i\to j\) 对应 \(\operatorname{Ext}^1(S_i,S_j)\)。

以上英文定义与实际采用范围按第五卷正文及已核读文献对照，不表示取得全部中文译名的官方逐条审定记录。

| 规则 | 设立原因 |
|---|---|
| 新增或改变重要术语时，记录主称、原文、定义范围、异名、依据和证据范围。 | 后续人员需要知道该选择解决了什么歧义，而不只是看到替换结果。 |
