\BookPart{域扩张与 Galois 理论}{b1:part:03}
\BookPartGuide
解一个多项式方程，常常意味着把原来的数域扩大。加入一个根以后，其他根是否也随之出现，新增的根之间有哪些代数关系，哪些变化仍然保持原有运算？这些问题把第二编的不可约性推进为域扩张的结构理论。Galois 理论所研究的自同构，正是保持基域而重新安排这些根的方式。

\ProseParagraphBreak
\chapref{b1:ch:14}先区分有限、代数与超越三种不同的限制。扩张次数是向量空间维数，超越次数则衡量代数独立的参数数目；两者不能互相代替。\chapref{b1:ch:15}通过分裂域、代数闭包和嵌入延拓，建立比较不同根的共同环境。\chapref{b1:ch:16}再考察根是否重复，证明可分次数的塔式公式和本原元素定理。代数闭包存在性与一般嵌入延拓中的选择原理，会在使用处明确指出。

\ProseParagraphBreak
\chapref{b1:ch:17}从多项式分裂域构造所有有限域，再用 Frobenius 计算子域、不可约多项式与具体运算。有限域乘法群的循环性所需的引理已经在本原元素定理之前证明，因而本原元素定理的证明不依赖第17章的有限域分类。\chapref{b1:ch:18}从乘法特征的独立性出发，建立迹、范数与判别式；这些方法既帮助计算，也用于估计不动域的扩张次数。

\ProseParagraphBreak
\chapref{b1:ch:19}是有限 Galois 理论的中心。先证明有限自同构群 \(G\) 与其不动域满足 \([L:L^G]=|G|\)，再建立中间域与子群的反向对应。这样每一次枚举中间域、计算合成域或识别商群，都有已完成的次数论证作为依据。三个共轭的三次子域可能彼此同构却在同一分裂域中处于不同位置，具体例子将反复提醒读者分清这两件事。

\ProseParagraphBreak
\chapref{b1:ch:20}研究循环扩张。Hilbert 第90定理解释范数为一与迹为零的方程，Kummer 理论及 Artin--Schreier 理论分别处理不同特征下的循环根式现象。\chapref{b1:ch:21}把这些结果用于分圆域、根式可解性和尺规作图。特征零下的根式可解性等价定理在此给出完整证明；正特征的附加问题单独说明。化圆为方需要 \(\pi\) 的超越性，正文给出指数函数论证的概要，并说明积分估计、共轭归结及省略步骤的原文位置。

\ProseParagraphBreak
图只表示主要次序。按不同学习目标，所需的关键结果可进一步分清如下。
\begin{itemize}
\item \textbf{有限 Galois 对应。}在域扩张的基本知识之后，依次掌握\cref{b1:thm:embedding-extension}的嵌入延拓、\cref{b1:thm:normal-embedding-criterion}的正规性判据、\cref{b1:thm:separable-embeddings}的嵌入计数与\cref{b1:cor:embedding-independence}的独立性，再读\cref{b1:thm:artin-fixed-field,b1:thm:finite-galois-correspondence}及其证明。迹、范数的算术应用不在这条论证之中。
\item \textbf{特征零的根式可解性。}有限 Galois 对应与可解群性质之外，需要范数的共轭元公式、乘法形式的\cref{b1:thm:hilbert90-multiplicative}，以及\cref{b1:thm:kummer-cyclic}的循环扩张根式生成。单位根的必要知识见\subsecref{b1:subsec:2003:01}；一般 Kummer 对应可以在读完根式可解性判据后补读。
\item \textbf{一般五次及高次方程。}证明\cref{b1:thm:radical-solvability}的判据还不足以推出一般五次方程不可解；后者另需独立参数的一般方程具有对称群，以及 \(S_n\) 在 \(n\geq5\) 时不可解的论证。这与下面对某个具体整数多项式计算 Galois 群的任务不同。
\item \textbf{具体 Galois 群的约化计算。}模素数后的不可约因子次数之所以给出群中的循环型，依据是\cref{b1:lem:reduction-cycle-type}。其证明另需中国剩余定理、有限域的 Frobenius 及\cref{b1:lem:integral-closure-elementary}的整性结果。这与独立参数的一般方程具有 \(S_n\) 群是不同的计算方法。
\item \textbf{尺规作图。}先用二次扩张塔判别可作图数及倍立方体、三等分角的障碍；正多边形的完整判据再补分圆域与有限 Galois 对应。上述判别不以 Hilbert 第90定理或一般 Kummer 对应为前提。
\item \textbf{无限 Galois 理论。}由一般嵌入延拓和有限 Galois 对应，进入\secref{b1:sec:2201}的相容自同构，再读\secref{b1:sec:2202}准备的拓扑与紧性证明，便可学习闭子群对应。有限域用于典型例子，根式与尺规作图可以暂缓。
\end{itemize}

本编使用前两编的群同态、正规子群、可解群、商环和多项式不可约性，也使用本科线性代数的基、维数、行列式与迹。阅读每个扩张时，宜先写清基域、特征和已加入的元素，再判断次数、正规性与可分性。涉及根式时检查单位根，涉及无限自同构群时检查连续性与闭性；这些假设往往正是一个看似合理的推广能否成立的关键。

\ProseParagraphBreak
本编可结合 Roman 的《Field Theory》\cite[Chapters 2--3, 6--7, 9, 11--13]{Roman2006FieldTheory}学习域扩张、有限域、Galois 对应与根式；Lang 的《Algebra》\cite[Chapters V--VI; Chapter VIII, \S 1]{Lang2002}可供进一步查阅代数扩张和超越扩张。
有限域的具体运算及算法另可参阅 Shoup 的《A Computational Introduction to Number Theory and Algebra》\cite[Chapters 19--20]{Shoup2008NumberTheoryAlgebra}。
有关实闭域、局部域和 Galois 上同调的进阶读物，分别在相关章与附录中介绍。
各章习题附有解答。建议先计算几个具体扩张及其自同构群，再阅读一般证明，以便理解定理的内容与适用条件。
