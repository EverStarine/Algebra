\section{Mittag–Leffler 条件}
\label{b4:sec:1304}

各层的稳定像条件允许逐层选择相容原像，即使原过渡映射并不满射。它消去可数塔的一次导出障碍，也解释完备化与 Milnor 型正合列中的附加项。

\subsection{稳定像条件}
\label{b4:subsec:1304:01}

过渡满射能使逐层提升继续进行，但它并非唯一有用的条件。即使某些元素始终不能从下一层提升，只要后来各层在当前层的像最终稳定，也足以排除一次导出障碍。

\begin{definition}\label{b4:def:mittag-leffler-tower}
设 \(R\) 为环，\(M=(M_n,u_n)\) 为左 \(R\)-模可数塔，\(u_{n,m}:M_m\to M_n\) 表示复合过渡映射，\(u_{n,n}=1\)。若对每个 \(n\)，存在 \(m_0\ge n\)，使
\[
\operatorname{im}u_{n,m}=\operatorname{im}u_{n,m_0}
\qquad(m\ge m_0),
\]
则称该塔满足\term[mittag-leffler-tiaojian]{Mittag–Leffler 条件}[Mittag--Leffler condition]，简称 ML 条件。
\end{definition}

过渡满射塔满足此条件。每层为 Artin 模的塔也满足，因为固定层中的像形成递降子模列；有限交换群塔、有限维向量空间塔都是例子。这里要求每个固定层的像最终稳定，并不要求所有层共用一个稳定指标。

\begin{lemma}\label{b4:lem:stable-image-tower}
设 \(R\) 为环，\(M=(M_n,u_n)\) 为满足 ML 条件的左 \(R\)-模可数逆向塔，以 \(S_n\subseteq M_n\) 记 \(M_m\to M_n\) 在 \(m\) 足够大时的稳定像。则 \(S=(S_n)\) 是过渡满射的子塔；商塔 \(Q_n=M_n/S_n\) 满足：对每个 \(n\)，所有足够远的过渡 \(Q_m\to Q_n\) 均为零。
\end{lemma}
\begin{proof}
取同时超过第 \(n\) 和 \(n+1\) 层稳定指标的 \(m\)。\(M_m\to M_n\) 经过 \(M_{n+1}\)，所以 \(u_n(S_{n+1})\subseteq S_n\)。任意 \(s\in S_n\) 都可从这同一个 \(M_m\) 提升，其在 \(M_{n+1}\) 的像属于 \(S_{n+1}\)，故限制映射满。最后，足够远的 \(M_m\to M_n\) 的像正是 \(S_n\)，模掉它以后映射为零。
\end{proof}

\subsection{\texorpdfstring{可数塔的 \(\varprojlim{}^1\) 消失判据}{可数塔的 lim1 消失判据}}
\label{b4:subsec:1304:02}

\begin{theorem}\label{b4:thm:mittag-leffler-vanishing}
设 \(R\) 为环，\(M\) 为满足 ML 条件的左 \(R\)-模可数塔。则
\(\varprojlim{}^1M_n=0\)。因此，对左 \(R\)-模可数逆向塔的短正合列 \(0\to A\to B\to C\to0\)，若 \(A\) 满足 ML 条件，取逆极限后仍为短正合列。
\end{theorem}
\begin{proof}
先处理每层的足够远过渡均为零的塔 \(Q\)。对任意 \(y\in\prod Q_n\)，令
\[
x_n=\sum_{m\ge n}u_{n,m}y_m.
\]
固定 \(n\) 时只有有限多个非零项，所以这是模中的有限和。相邻两式相减得到 \(x_n-u_nx_{n+1}=y_n\)，故 \(\Delta_Q\) 满，\(\varprojlim{}^1Q_n=0\)。

对一般 ML 塔用\cref{b4:lem:stable-image-tower}分成 \(0\to S\to M\to Q\to0\)。\(S\) 的过渡满射，\(Q\) 满足刚证明的条件，所以两者的一次导出极限为零。\cref{b4:thm:countable-derived-limit}的六项正合列于是给出 \(\varprojlim{}^1M_n=0\)。末项结论再次应用同一六项正合列。
\end{proof}

ML 条件充分保证一次导出极限消失，但并非必要。例如设 \(p\) 为素数，取每层为 \(\mathbb Z_p\)、过渡为乘 \(p\) 的塔，固定层的像 \(p^m\mathbb Z_p\) 严格递降，故不满足 ML；但对任意 \((y_n)\) 可定义
\[
x_n=\sum_{j\ge0}p^j y_{n+j}\in\mathbb Z_p.
\]
此式的意义是：模 \(p^r\) 时只取前 \(r\) 项，它们随 \(r\) 相容，因而由逆极限定义一个元素。于是 \(x_n-px_{n+1}=y_n\)，\(\Delta\) 仍满。严格递降可由 \(p^m\) 模 \(p^{m+1}\) 非零检验；这里无需使用分析意义的级数收敛。

\ProseParagraphBreak
可数塔的乘积计算、稳定像方法及条件范围可分别对照 Weibel\cite[Definition 3.5.1, Corollary 3.5.4, Definition 3.5.6, Proposition 3.5.7]{Weibel1994HomologicalAlgebra}。

\subsection{完备化与 Milnor 型正合列}
\label{b4:subsec:1304:03}

设 \(R\) 为交换环，\(I\) 为理想，\(0\to A\to B\to C\to0\) 为 \(R\) 模短正合列，将 \(A\) 识别为 \(B\) 的子模。记 \(R\) 模 \(M\) 的 \(I\)-进完备化为 \(\widehat M=\varprojlim_n M/I^nM\)。对每个 \(n\ge1\)，有短正合列
\[
0\to A/(A\cap I^nB)\to B/I^nB\to C/I^nC\to0\qquad(n\ge1).
\]
因为 \(A\cap I^{n+1}B\subseteq A\cap I^nB\)，左端商模塔的过渡映射满射，因而满足 ML 条件。由\cref{b4:thm:mittag-leffler-vanishing}，取逆极限仍得到短正合列
\[
0\longrightarrow\varprojlim_n A/(A\cap I^nB)
\longrightarrow\widehat B\longrightarrow\widehat C
\longrightarrow0.
\]
其中左端按 \(B\) 在 \(A\) 上诱导的滤过计算；要把它识别为通常的 \(\widehat A\)，还需比较 \(A\cap I^nB\) 与 \(I^nA\)。

\ProseParagraphBreak
若 \(R\) Noether 且 \(B\) 有限生成，第三卷定理13.2.1的 Artin–Rees 引理给出某个 \(c\)，使
\[
I^nA\subseteq A\cap I^nB\subseteq I^{n-c}A\qquad(n\ge c).
\]
第一组包含给出 \(\widehat A\to\varprojlim_n A/(A\cap I^nB)\)，第二组在指标平移 \(n\mapsto n+c\) 后给出逆向映射。两次复合均由相应商模塔的过渡映射诱导，取逆极限后成为恒等。因此两个滤过给出同一个完备化，前面的正合列便成为
\[
0\longrightarrow\widehat A\longrightarrow\widehat B
\longrightarrow\widehat C\longrightarrow0.
\]
这也得到第三卷定理13.3.5的完备化正合性：ML 条件使诱导滤过的逆极限列正合，Artin–Rees 则利用 Noether 性和有限生成性，把这个诱导滤过的完备化识别为 \(I\)-进完备化。

\ProseParagraphBreak
对复形组成的逆系统，一次导出还记录了“先取上同调”与“先取逆极限”之间的差别。各次数模塔的 ML 条件保证乘积差映射逐次数满射，从而可以在复形层面应用同调长正合列；若相应的同调塔也满足 ML 条件，一次导出修正项还会消失。下面的短正合列称为\term[milnor-zhenghelie]{Milnor 正合列}[Milnor exact sequence]。

\begin{theorem}[Milnor 型正合列]\label{b4:thm:milnor-exact-sequence}
设 \(R\) 为环，\((C_n)_{n\ge0}\) 为左 \(R\)-模上链复形的逆向塔。假定对每个次数 \(j\)，模塔 \((C_n^j)_n\) 满足 ML 条件。则对每个整数 \(q\)，有自然短正合列
\[
0\longrightarrow\varprojlim{}^1 H^{q-1}(C_n)
\longrightarrow H^q(\varprojlim C_n)
\longrightarrow\varprojlim H^q(C_n)\longrightarrow0.
\]
若同调塔 \((H^{q-1}(C_n))_n\) 也满足 ML 条件，右侧比较映射是同构。
\end{theorem}
\begin{proof}
记复形塔的过渡映射为 \(u_n:C_{n+1}\to C_n\)，在乘积复形上定义
\[
\Delta^j:\prod_n C_n^j\longrightarrow\prod_n C_n^j,
\qquad
\Delta^j((x_n))=(x_n-u_n^j(x_{n+1}))_n.
\]
各 \(u_n\) 与微分交换，所以 \(\Delta\) 是复形映射。逐次数的相容性给出
\[
\ker\Delta^j=\varprojlim_n C_n^j
=(\varprojlim_n C_n)^j.
\]
由\cref{b4:thm:countable-derived-limit}及\cref{b4:thm:mittag-leffler-vanishing}，假设中的各次数 ML 条件又给出
\[
\operatorname{coker}\Delta^j
\cong\varprojlim{}^1_n C_n^j=0.
\]
因此 \(\Delta\) 逐次数满射，确实得到复形的短正合列
\[
0\longrightarrow\varprojlim C_n\longrightarrow\prod_n C_n
\xrightarrow{\Delta}\prod_n C_n\longrightarrow0.
\]
由\cref{b4:prop:products-cohomology}，乘积复形的上同调等于上同调模的积；\(\Delta\) 在上同调上诱导的态射就是对应的乘积差映射，记为 \(\Delta_q\)。同调长正合列的相关片段为
\[
\begin{gathered}
\prod_n H^{q-1}(C_n)
\xrightarrow{\Delta_{q-1}}\prod_n H^{q-1}(C_n)
\xrightarrow{\partial}H^q(\varprojlim C_n)\\
\longrightarrow\prod_n H^q(C_n)
\xrightarrow{\Delta_q}\prod_n H^q(C_n).
\end{gathered}
\]
再次应用\cref{b4:thm:countable-derived-limit}，有
\[
\operatorname{coker}\Delta_{q-1}
\cong\varprojlim{}^1 H^{q-1}(C_n),
\qquad
\ker\Delta_q=\varprojlim H^q(C_n).
\]
正合性使前一个余核经 \(\partial\) 嵌入 \(H^q(\varprojlim C_n)\)，其像是右侧比较映射的核；比较映射的像恰为后一个核。截取便得到所述短正合列。原短列及同调连接态射均自然，故所得短列自然。若 \((H^{q-1}(C_n))_n\) 也满足 ML 条件，\cref{b4:thm:mittag-leffler-vanishing}使左端修正项为零，比较映射即为同构。
\end{proof}

这个上链版本可与 Weibel\cite[Theorem 3.5.8, Variant]{Weibel1994HomologicalAlgebra}对照；链版本的修正项则在 \(q+1\) 次。

\begin{example}\label{b4:exm:milnor-nonzero-correction}
设 \(p\) 为素数，令 \(C_n\) 是次数 \(0,1\) 的复形 \(\mathbb Z\to\mathbb Z/p^{n+1}\)，微分为商映射；过渡为恒等与约化。各次塔都过渡满射，但 \(H^0(C_n)=p^{n+1}\mathbb Z\)、\(H^1(C_n)=0\)。极限复形为 \(\mathbb Z\to\mathbb Z_p\)，所以
\[
H^1(\varprojlim C_n)=\mathbb Z_p/\mathbb Z
=\varprojlim{}^1H^0(C_n),
\qquad \varprojlim H^1(C_n)=0.
\]
这里新增的一次同调完全来自相容性障碍，而不是任何有限层的一次同调。
\end{example}
