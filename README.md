# 代数学

《代数学》是 R. EverStarine 编写的五卷本中文教材。从群、环、域出发，逐步进入模、交换代数、同调代数和表示论。各卷的目录、先修关系与选读范围见[计划纲要](工作记录/计划纲要.md)。

## 五卷导览

| 卷次 | 主要内容 | 阅读 |
|---|---|---|
| 第一卷：群、环、域与 Galois 理论 | 群与对称、整除和多项式、域扩张与方程 | [正文 PDF](Book1.pdf) |
| 第二卷：模、多线性代数与非交换环 | 模与张量积、标准形、半单结构与非交换环 | [正文 PDF](Book2.pdf) |
| 第三卷：交换代数与代数几何方法 | 素谱与局部化、计算与维数、局部同调和几何初步 | [正文 PDF](Book3.pdf) |
| 第四卷：范畴与同调代数 | 范畴、复形与消解、同调方法和导出范畴 | [正文 PDF](Book4.pdf) |
| 第五卷：表示论：有限群、箭图与李代数 | 有限群表示、箭图、李代数及相关专题 | [正文 PDF](Book5.pdf) |

五卷的正文与附录均已形成初稿，仍在修订和审核。第五卷四编、五篇附录及后记已写齐。各卷的实际完成度与审核状态见[审核进度](工作记录/审核进度.md)。

## 怎样阅读

具备本科线性代数、集合与映射以及基本证明训练的读者，可以从第一卷开始。读过群、环的基础后，也可以转入第二卷的模论，再按兴趣学习交换代数、同调代数或表示论。不必依卷次通读；各编导读说明了所需基础和可以暂缓的内容。

## 源码与构建

五卷分别以 `BookN/BookN.tex` 为源码入口，共用 `Shared/` 中的样式与书目。写作约定见[写作规范](写作规范/写作规范.md)，编译与资料维护细节见[工作流程说明](写作规范/工作流程说明.md)。在项目根目录构建单卷，例如：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Book 1
```

将 `1` 改为其他卷号即可构建对应卷；省略 `-Book 1` 则构建五卷。

结构检查分别使用 `scripts/Check-Outline.ps1` 和 `scripts/Check-TextStructure.ps1`。已编译 PDF 的书签检查使用 `scripts/Check-PdfBookmarks.py`，需使用安装了 `pypdf` 的 Python。正式源码与工具均不依赖旧的 `tmp/` 内容；该目录中的构建文件由脚本重新生成。
