## 一、调整后的取舍

《对合之书》对二次型、中心单代数和古典群之间的联系很有启发，但完整引入其理论，会显著增加第二卷的专门内容。此次以已有知识能自然接上的概念、证明和算例为主；对合存在性的一般判据、一般 Clifford 不变量和分类理论不再列为第二卷新增正文的共同要求。

不变量理论的情况不同：本项目已经安排第五卷第22章“不变量理论与商”，它可以把有限群表示、多项式、分次环、消去和代数群联系起来。值得优先充实这一现有章，同时在前几卷补少量算例。这里主要指群作用下的多项式不变环、生成元与关系，以及相应的商；一般的维数、秩和同构不变量不能替代这些专门内容。

本次建议保持五卷的编章安排，以“第二卷及第五卷适量补对合，第五卷第22章系统讲不变量，第一、三卷提供具体计算”为基本安排。

## 四、第五卷第22章的建议细化

章名仍为“不变量理论与商”，仍放在第五卷现第22章，保留选读章性质。建议由四节细化为七节，不新增章号。前四节以有限群为主，所需基础在本章重述，可以在学完第五卷第一编、具备多项式环基础后阅读，不要求先读完整个李代数部分。

以下内容现已同步正式纲要、TeX 标题骨架与证明任务，尚未撰写这些节的正文。

### 22.1　群作用与不变多项式

- 22.1.1　线性作用、函数上的作用与不变子环
- 22.1.2　有限群的轨道与不变量分离
- 22.1.3　平均法与 Reynolds 算子

从置换变量、循环群的对角作用、平面同时变号等例子出发，明确 k[V] 是 V 的对偶空间的对称代数。证明平均投影及其对不变子环的线性性，说明它通常不是环同态。几何轨道的论述固定代数闭域或明确改用几何点；特征不整除群阶的条件与平均法一起写出。

### 22.2　有限生成与次数界

- 22.2.1　轨道多项式与整性
- 22.2.2　有限模性及 Artin–Tate 引理
- 22.2.3　有限群不变量的有限生成
- 22.2.4　Noether 次数界与有效计算

有限生成按“轨道多项式—整性—有限模—Artin–Tate”完整证明，不以 Noether 环的任意子环仍为 Noether 环这一错误断言代替。有限群不变环的有限生成不要求群阶可逆；平均法失效不能被说成有限生成也失效。

Noether 的生成次数界先在特征零下给出完整证明，即可以选择次数不超过群阶的齐次生成元，用来说明何时枚举有限多次的平均单项式足以找齐生成元。更广的非模情形如不展开证明，明确另列来源；模特征的不同现象给一个算例。线性约化代数群的有限生成统一放到22.7，不混入本节的有限群证明。

### 22.3　Hilbert 级数与 Molien 公式

- 22.3.1　齐次不变量的维数与特征标
- 22.3.2　Molien 公式
- 22.3.3　循环群与小型反射群的计算

主公式在复数域或特征零的明确范围内推导。把各次对称幂上的平均迹组织为生成函数，证明 Molien 公式，再用小群算出完整有理函数。

说明 Hilbert 级数可以检验给定生成元和关系是否遗漏，但级数本身不唯一决定环的乘法，也不能只从一个分母形式就认定已经找到自由生成元。正特征时不能把域内的迹值直接当成整数维数套用同一证明。

### 22.4　生成元、关系与 Gröbner 计算

- 22.4.1　齐次生成元的搜索与完备性
- 22.4.2　用消去求生成元之间的关系
- 22.4.3　用 Hilbert 级数核验展示
- 22.4.4　循环作用的完整算例

选定特征不为2的平面同时变号作用：
\[
k[x,y]^{C_2}=k[x^2,xy,y^2]
\cong k[u,v,w]/(uw-v^2).
\]
证明所有不变单项式都由三个生成元产生，再证明关系理想恰为所示主理想，最后用 Hilbert 级数核对。u、v、w 在原多项式分次下的次数都是2，不能在计算中悄悄改成次数1。

对于一般候选生成元，计算其关系理想只得到它们生成的子代数，仍需证明该子代数就是整个不变环。可用已证次数界、逐次分解或已知满射加 Hilbert 级数比较完成，不能用消去算法本身代替生成性的证明。

### 22.5　经典不变量与协变式

- 22.5.1　对称多项式与反射群的例子
- 22.5.2　矩阵共轭下的特征多项式与迹
- 22.5.3　向量与对偶向量的配对不变量
- 22.5.4　二元型的判别式与协变式

对称多项式给一个可以完整证明的基本定理；有限反射群的一般 Chevalley–Shephard–Todd 定理可作选读陈述，不承诺以几页篇幅完成完整分类或一般证明。

单矩阵共轭以特征多项式系数为不变量，特征零下再说明与各次迹的关系。它们不能区分所有非半单共轭轨道；用两个不同 Jordan 型的矩阵展示这一点。若引入多个矩阵的迹字不变量，必须把一般生成定理与当前具体计算分别标明。

经典群至少完整处理 GL(V) 同时作用于向量与对偶向量时的配对不变量，写清相应基本定理和依赖；正交、辛情形选一个 Gram 型算例。二元型至少给出一个低次例子，区分不变量、相对不变量与协变式；判别式在 GL₂ 与 SL₂ 下的变换性质不能混写。完整经典第一、第二基本定理不全塞进一节。

### 22.6　仿射商与轨道闭包

- 22.6.1　由不变环构造仿射商
- 22.6.2　有限群商与有限态射
- 22.6.3　代数环面作用与轨道闭包
- 22.6.4　矩阵共轭与闭轨道

以有限群情形建立代数与几何之间的关系，再给一个环面作用的非闭轨道例子。有限群在代数闭域上的仿射簇，其几何轨道可以由不变函数分离；一般无限代数群则不能直接照搬“商点等于轨道”的说法。

对闭轨道代表的唯一性等一般结果，写清所用群、底域和有限生成条件，并承担相应证明或明确外引。用矩阵的半单部分与轨道闭包解释为什么相同的多项式不变量并不意味着两个矩阵共轭。

### 22.7*　约化群与几何不变量理论初步

- 22.7.1　线性约化性与 Hilbert 有限生成定理
- 22.7.2　正特征、几何约化性及适用范围
- 22.7.3　稳定性与射影商的一个例子

把第21章的有理表示语言用于不变环。特征零下的有限生成取可在本章展开的版本；正特征约化群的有限生成明确涉及更深理论，不能用对有限群求平均的公式代替。

GIT 部分以一个明确的线性化和低维射影例子解释半稳定、稳定及商的区别。Hilbert–Mumford 判据、模空间构造和变分 GIT 等完整理论留给代数几何专著，避免一节许诺一个完整课程。

## 六、证明与取舍的检查项

1. 核心链条是：作用与不变环、有限生成、有效生成、关系、级数、商。应分别说明每一步解决什么问题。
2. 有限群、线性约化群、约化群三类假设分别写清；尤其不能把特征零结论无标记搬到正特征。
3. Reynolds 算子的投影性质、不变子环线性与乘法性是不同条件。
4. 求到关系理想不等于证明候选元生成整个不变环；Hilbert 级数比较也需要明确的分次映射。
5. 多项式不变量分离闭轨道的结论，不能误写成分离所有轨道。
6. “经典不变量与协变式”须有可计算的对象；不以列举一串基本定理名称代替证明和算例。
7. SAGBI 的一般算法、模不变量的完整理论、一般有限反射群分类及完整 GIT 暂不列入共同讲授内容；需要时作为进一步阅读。
8. 对合内容以现有矩阵、四元数和古典群例子为主，不通过多处增补变相加入原方案的两章体量。
